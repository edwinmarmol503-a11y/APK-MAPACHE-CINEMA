# Mapache Cinema para Android

**Estudio Lumera · La Última Noche**

Aplicación Android de Mapache Cinema, con niveles y 43 pistas/efectos incluidos para jugar sin conexión. La clasificación compartida necesita internet.

La APK y el proyecto para compilar se publican en la sección [Releases](https://github.com/edwinmarmol503-a11y/APK-MAPACHE-CINEMA/releases).

Los avances de la app se guardan por separado de los de Chrome.
